## Decisions

- Notion이 프로젝트·선택·세션의 원본이다. 자체 도메인 DB와 브라우저 영속 저장을 추가하지 않았다. Durable Object에는 요청 영수증과 안전 잠금만 보관하며 응답 데이터 스냅샷은 저장하지 않는다. 중복 요청을 다시 받을 때 현재 상태는 새로 조회한다.
- 여러 프로젝트가 선택돼 있어도 유효한 열린 로그가 정확히 하나이면 그 로그를 먼저 END할 수 있도록 했다. 세션 중 선택 잠금 때문에 복구가 막히는 상황을 피한다.
- 앱 데이터 없는 별도 데모를 명시적으로 제공한다. 운영 빌드에서는 데모가 활성화되지 않는다.
- 정상 START/END에는 확인 모달을 넣지 않았다. 불확실한 쓰기만 Notion 확인과 잠금 해제를 요구한다. API는 자동으로 toggle을 반복하지 않는다.
- 지원 런타임보다 미래인 2026-10-01 호환 날짜가 테스트에서 거부돼 현재 workerd가 지원하는 2026-09-30으로 고정했다. 구형 Vitest pool 패키지는 최신 공식 플러그인으로 교체했다.
- 동시 요청 테스트의 외부 Promise 제어가 Windows workerd를 중단시켜 요청 내부 지연 방식으로 바꿨고 전체 테스트가 통과했다. 시작 시각이 잘못된 로그에서 날짜 포맷 오류가 날 수 있어 화면 안내로 보완했다.
- 잠긴 프로젝트도 읽을 수 있도록 행 전체를 흐리게 만드는 스타일을 제거하고 모바일 타이머 글자를 키웠다.
- J님은 Notion 토큰을 Worker secret에 직접 등록하는 방식을 선택했다. 토큰을 채팅이나 프런트엔드로 받지 않는다.
