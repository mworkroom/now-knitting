## Decisions

- 첫 검사에서 Wrangler 로그 경로와 esbuild 상위 디렉터리 접근 권한 오류가 발생했다. 로그를 로컬 `.wrangler`로 지정하고 허용된 일반 권한으로 전체 검사를 재실행해 통과했다. Chrome 기본 실행 경로 탐색도 실패해 실제 설치 경로를 명시했다.
- 브라우저 검증 스크립트가 도구 호출 사이의 fixture 변수 변경을 반영하지 않아 대기 시간이 초과됐다. fixture 제어를 같은 호출 안의 객체로 정리한 뒤 성공·실패 흐름을 확인했다. 앱 코드 오류는 아니었다.

## Decisions - 프로젝트 상세와 패턴 표시

- PDF 원본과 표시를 분리해 PDF 용량·업로드를 피한다. R2·결제 서비스·새 binding/migration을 추가하지 않는다. 기존 인증 범위를 이용한다.
- 파일명보다 해시를 사용해 잘못된 도면에 표시가 복원되는 것을 막는다. 같은 PDF라도 프로젝트별로 표시를 분리한다. 좌표는 페이지 비율로 저장해 확대·화면 폭 변화에도 위치가 유지된다. 텍스트 선택에 의존하지 않아 스캔 PDF에도 같은 방식을 사용할 수 있다.
- 삭제도 기록으로 남겨 오래된 기기·백업이 삭제된 표시를 되살리지 않게 한다. 백업 가져오기는 교체가 아닌 병합이다. 문서당 5,000개 작업, 전송당 100개로 제한했다. [Cloudflare bulk put 한도](https://developers.cloudflare.com/durable-objects/api/legacy-kv-storage-api/#put)의 128개 안에 메타데이터까지 들어가게 한다.
- PDF.js 최신 API에서 문서 destroy 대신 loading task destroy를 사용하고 렌더링을 직렬화했다. 첫 타입 검사에서 초기 useRef 값·아이콘 이름·destroy API를 수정했다.
- 객체 재생성 테스트가 응답 body를 소비하지 않아 런타임의 요청 종료 대기에서 시간 초과됐다. 응답을 소비하고 공식 alarm helper로 검사해 통과했다. 실제 장기 보관 정책 오류가 아니었다.
- 삭제 취소는 새 불변 ID를 만들므로 이전 Undo 항목도 복원 ID를 따라가도록 보완했다. 연속 Undo 브라우저 검사로 확인했다.
- Chrome 터치 검증에서는 그리기 후 버튼의 pointerup은 발생하지만 click이 전달되지 않는 경우를 확인했다. 모드 선택은 터치 pointerup도 처리하고 기존 키보드·마우스 click을 유지한다. touch-action과 user-select로 그리기 제스처를 제어하며 보완 후 전환이 통과했다. 실제 Safari 원인은 아직 확인하지 않았다.
- 작은 화면에서는 읽을 수 있는 글자 크기를 유지하고 카드·태그·무게 버튼을 줄바꿈한다. 목업의 베이지·보라·serif는 사용하지 않는다는 J님 요청을 우선했다.

- 속성 ID는 소스별로 영구 저장한다. 삭제한 속성을 같은 이름의 새 속성에 자동 연결하지 않는다. 이번 이름 변경 보호는 세 조건에 한정하고 프로젝트 선택·시간 기록 연결은 기존 방식을 유지했다.
- checkbox·boolean formula 및 명시적인 Yes/No 문자열만 해석한다. 뜻이 불분명한 문자열이나 변경된 타입은 미확인으로 남긴다.
- 첫 검증에서는 샌드박스가 Wrangler 로그·번들 경로 접근을 제한했다. 빌드는 성공하고 테스트도 통과했으나 dry-run이 실패해 승인된 로컬 검증을 다시 실행했고 최종 전체 검증이 통과했다. 화면 검사 스크립트는 검색 입력의 실제 접근성 역할인 searchbox로 교정했다. 320px의 미확인 뱃지는 가운데 점을 빼고 여백을 줄여 글자 크기를 유지했다.
